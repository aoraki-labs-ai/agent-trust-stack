## 怎么读这张图

**从下往上，每层的产品数量在增加、单价在下降、可替换性在上升。**

- **L0 最集中。** 全世界能做 GPU 机密计算的厂商，一只手数得过来。这一层的壁垒是流片能力，
  也意味着这一层的任何漏洞（见[第 07 章](/agent-trust-stack/07-cold-water/)）会同时影响上面所有层。
- **L1 是唯一的接缝。** 远程证明既属于「机密」也属于「可验证」——它本身就是一份关于硬件状态的、
  可被第三方验签的声明。整个栈里能把「相信我」升级为「你自己验」的，只有这一样东西。
- **L2 最难站。** 上面被 L3 的协议标准化，下面被 L0 的芯片厂商往上打。云厂商可以直接把 L2 做成自家 VM 类型，
  独立厂商的空间被两头挤。
- **L3 在打标准战。** 支付网络、CDN、以太坊社区三套方案并行，见[第 02 章](/agent-trust-stack/02-demand/) 2.4。
- **L4 预算最确定。** 它几乎不含新密码学，全是流程、日志与凭证管理——但它是唯一一层有监管硬日期的。

一家公司站在 L0–L1 是技术壁垒，站在 L3–L4 是分销壁垒；站在 L2 最难，因为两种壁垒它都不占。

<div class="falsify">
<strong>怎么证伪</strong>
如果有独立厂商在 L2 长期维持高毛利且不被云厂商吃掉——例如公开财报显示毛利率稳定在 70% 以上、
净留存率高于 120%——那「L2 最难站」这个判断就不成立，它可能反而是控制点。
可执行的检查：跟踪 L2 阵营中已上市或披露财务数据的公司。

## 怎么证伪（本章汇总）

| 结论 | 什么样的观测会推翻它 |
|---|---|
| L2 是最难站的位置 | 某 L2 厂商长期高毛利且未被云厂商吃掉 |
| 远程证明是栈里唯一的接缝 | 出现不依赖硬件证明、却能让第三方验证机密性的方案 |
| 越靠上竞争越激烈 | L0 出现三家以上势均力敌的新进入者 |
